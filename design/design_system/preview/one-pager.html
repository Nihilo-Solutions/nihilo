Problem

The client's analyst team spent an estimated 14 hours per week manually reconciling counterparty exposures across three siloed systems of record. Existing SaaS AI tools were blocked by the compliance office — sensitive counterparty data could not leave the client's Azure tenancy under any circumstance.

Approach

We deployed a tenant-local RAG pipeline in the client's own Azure subscription using Azure AI Search, Fabric for ingestion, and a policy-sandboxed agent for reconciliation narration. All embeddings, vector indexes, and audit logs remained inside the tenant VNet — no external model provider ever saw raw data.

  • PII-redacted ingestion from three sources, incremental CDC
  • Hybrid retrieval (dense + BM25) with LLM reranking
  • Agent with deterministic fallback for exception paths
  • Human-in-the-loop approval for all write-back actions

Result

Production deployment in six weeks. 42% reduction in manual analyst hours against the baseline workflow, with every action evidenced in an audit-grade log. Zero external data-egress events through the production pilot. The SOC 2 evidence package was produced by construction during the build, not retrofitted.

“We stopped renting our data to public models. Production in six weeks.”
